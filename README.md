# YouTube ショートブロッカー

YouTube のショートを**再生させず**、UI からも消す Chrome 拡張（Manifest V3）。

ショートは一度見ると増えます。1本再生した時点でレコメンドが学習し、ホームに棚が増え、
関連動画にも混ざり、それをまた目にして再生してしまう。だから隠すだけでは足りません。

この拡張は**再生が始まる前に離脱する**ので、視聴として記録されず、**再生履歴にも
残りません**。レコメンドが太らないのでショートが増えません。非表示にするだけの拡張とは
そこが違います。

外部への通信はありません。権限は `storage` ひとつだけです。

## インストール

1. このリポジトリを clone または ZIP でダウンロードする
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択

ツールバーのアイコンから ON / OFF を切り替えられます（リロード不要）。

> `world: "MAIN"` を使うため **Chrome 111 以降**が必要です。

## どうやって止めているか

SPA は入口が多いので、5層で守っています。

| 層 | 止めるもの |
|---|---|
| 1 | `/shorts/` を直接開いた / 履歴で戻った → 再生前にホームへ離脱 |
| 2 | SPA 内のショートへの `pushState` → 無視する |
| 3 | ショートへのリンクのクリック → `preventDefault` |
| 4 | サイドバー・棚・サムネイル → CSS で非表示 |
| 5 | 1〜4 をすり抜けてプレーヤーが出た場合 → 700ms ごとに検出して離脱 |

層1のおかげで再生履歴に残りません。層5は YouTube 側の DOM 変更で 1〜4 が破れたときの
保険で、最悪でも1秒以内に復帰します。

## 構成

| ファイル | ワールド | 役割 |
|---|---|---|
| `main.js` | MAIN | 遷移ブロック、リンククリック抑止、`href` を持たない要素へのマーキング |
| `bridge.js` | 隔離 | 設定の読み出し、CSS の出し入れ、MAIN への通知 |
| `popup.js` / `popup.html` | – | ON / OFF トグル |

`main.js` が MAIN ワールドで動く理由は2つあります。

- ページ本体の `history.pushState` をパッチする必要がある。隔離ワールドの `history` は
  別オブジェクトなので、差し替えてもページ側の呼び出しには効かない
- サイドバーの「ショート」は `<a href>` を持たず、Polymer の `.data`（ページの JS が
  要素に代入したプロパティ）を読まないと判定できない。これは隔離ワールドからは見えない

その代償として MAIN ワールドでは `chrome.*` が使えないため、隔離ワールドの `bridge.js` と
`postMessage` で繋いでいます。設定の正は `chrome.storage.local` ですが非同期なので、
`document_start` の時点では `bridge.js` がミラーした `localStorage` を同期的に読んで
チラつきを防いでいます。

消す対象のうち `<a href="/shorts/...">` を持つものは CSS の `:has()` だけで片付けて、
JS は `href` を持たないものにしか触りません。YouTube のように DOM が激しく動くページで
`MutationObserver` を回しっぱなしにしないための分担です。

## 開発

```sh
npm test
```

依存パッケージはありません（`node --test` と `node:vm` だけ）。`main.js` をスタブの
文脈で実行し、`data-no-shorts` が正しく付くかを見ています。

### 循環参照のテストを消さないこと

`navUrl` の探索は URL が見つかるまでオブジェクトグラフを舐めます。Polymer のデータは
親子で相互参照を持つため、**URL を持たない項目と循環参照が揃うと再帰が止まりません**。
`tests/main.test.js` の `cyclic` がそのケースです。

止め方は2つ入れてあり、**どちらか片方だけでも再帰は止まります**。

| ガード | 役割 |
|---|---|
| `MAX_DEPTH` | 深さで打ち切る。無限再帰を原理的に防ぐ |
| `seen` (`WeakSet`) | 訪問済みを覚える。同じオブジェクトを何度も舐めないための性能ガード |

冗長なのは意図的です。ただし**テストが落ちるのは両方を外したときだけ**なので、
片方を消してもテストは通ってしまいます。どちらも残してください。

なお探索に `for-in` を使ってはいけません。プロトタイプチェーン側まで列挙してしまい、
Polymer の要素では余計なものを大量に舐めます（`Object.keys` を使っています）。

## 既知の制限

- チャンネルページの「ショート」タブだけは `href` も `.data` も取れないため、表示
  ラベル（`main.js` の `TAB_LABELS`）で判定しています。YouTube の UI 言語を日本語・
  英語以外にする場合はここに追加してください
- YouTube の DOM は頻繁に変わるため、棚の要素名（`grid-shelf-view-model` など）は
  いずれ効かなくなる可能性があります。その場合は `bridge.js` のセレクタを更新します
- この拡張には Tampermonkey 版の前身がありますが、同期していません。ユーザースクリプト
  版はサイドバーの「ショート」を CSS の `:has()` だけで狙っているため、`href` を持たない
  表示のときは消えません。両方を入れる必要はありません
